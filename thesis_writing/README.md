# 大论文写作工作区

本文件夹集中存放大论文相关材料，避免和项目根目录中的代码、仿真结果、模型训练文件混在一起。

## 目录说明

- `plan/`：写作计划、论文大纲、章节架构、进度追踪和任务包。
- `chapters/`：大论文各章节正文。
- `refs/`：文献证据图谱、关键结论和数据来源核查。
- `figures/`：论文图表清单和数据来源登记，不直接存放所有原始图。
- `tables/`：表格清单、字段说明和表格来源登记。

## 推荐写作顺序

1. 先确认 `plan/outline.md` 的章节结构。
2. 建立 `refs/evidence-map.md`，核对关键数据和文献来源。
3. 从 `chapters/01_Introduction.md` 开始逐章扩写。
4. 每完成一章，同步更新 `plan/progress.md`。
