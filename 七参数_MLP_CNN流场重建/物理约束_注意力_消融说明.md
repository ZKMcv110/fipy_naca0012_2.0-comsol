# 物理约束、注意力机制与消融实验说明

## 1. 当前可证明的事实

当前最终主线是：

```text
七参数 -> MLP Encoder -> CNN Decoder 重建 u/v/p/T
                 -> MLP Head 预测 Nu/f -> eta
```

已真实运行并验证的当前主线结果包括：

- 1000 组统一网格流热场数据集；
- MLP-CNN 多任务训练；
- DE 优化 eta；
- 二维 CFD 复算；
- 三维芯片级散热器迁移验证；
- 参数敏感性分析；
- MLP-CNN 3 折短训稳定性验证。

## 2. 物理约束怎么写

当前新主线已经实际使用的物理一致性约束是：

```text
L_eta
```

即 eta 不作为独立网络输出，而是由预测得到的 `Nu` 和 `f` 按下式计算：

```text
eta = (Nu / Nu0) / (f / f0)^(1/3)
```

训练损失为：

```text
L = L_u + L_v + L_p + L_T + alpha*L_Nu + beta*L_f + gamma*L_eta
```

因此，当前论文中可以写：

> 本文在多任务监督中加入综合性能指标一致性损失，使代理模型预测的 Nu、f 与 eta 之间保持物理定义一致。

不能写成：

> 当前 MLP-CNN 已完整加入 Navier-Stokes 方程残差或完整 PINN 约束。

## 3. PDE 物理约束的可扩展设计

项目中存在旧的 PDE-PINN 探索路线和相关计划文件，说明连续性、能量方程、边界条件损失有过设计，但它们没有并入当前 MLP-CNN 主训练结果。因此正文中应写成“可扩展物理约束设计”或“后续增强方向”。

可设计为：

```text
L_total = L_field + alpha*L_Nu + beta*L_f + gamma*L_eta
          + lambda1*L_cont + lambda2*L_energy + lambda3*L_bc
```

其中：

- `L_cont`：连续性约束；
- `L_energy`：温度场平滑、能量方程残差或 Laplacian 辅助约束；
- `L_bc`：入口、出口、壁面和流固界面边界一致性约束。

论文写法：

> 在当前实证模型中，物理一致性主要通过 eta 定义约束和 u/v/p/T 场监督体现；PDE 残差约束作为可扩展模块给出，不作为本文主要实验结论。

## 4. 注意力机制怎么写

旧工程中存在 CBAM 和 PI-CNN-CBAM 结果，但它们属于几何掩码/图像输入路线，不属于当前“七参数到流热场重建”的最终主线。

因此可以写：

> 注意力机制在旧的 PI-CNN-CBAM 路线中已经作为对照验证过，可说明通道注意力和空间注意力对关键流热区域具有增强作用。

但不能写：

> 当前 MLP-CNN 流热场重建模型已经训练并验证了 CBAM 注意力版本。

当前主线中的注意力模块建议作为可扩展结构：

```text
七参数 -> MLP Encoder -> latent z
latent z -> SE/CBAM Attention -> CNN Decoder -> u/v/p/T
latent z -> MLP Head -> Nu/f
```

推荐插入位置：

- CNN Decoder 中间层之后加入 SE 通道注意力；
- 或在重建场的浅层特征图上加入 CBAM 通道与空间注意力；
- 或对 `u/v/p/T` 四通道设置通道注意力权重。

## 6. 参数敏感性结论

当前新主线已完成真实敏感性分析：

- 数据驱动相关性；
- 随机森林特征重要性；
- DE 最优点附近代理模型局部扰动。

主要结论：

- eta 的随机森林置换重要性最高参数为 `Ts`；
- DE 最优点附近局部扰动中，eta 最敏感参数同样为 `Ts`；
- 其次为 `Tb` 和 `theta`。

结论边界：

> 该结果是基于当前样本分布和代理模型的统计/局部扰动敏感性分析，不等同于固定其余参数的严格 CFD 单因素扫描。
