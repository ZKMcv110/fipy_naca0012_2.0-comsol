# 项目架构补充：MLP-CNN 流热场重建主线

本补充文件用于替代旧“几何掩码最终主线”的表述，但不直接覆盖根目录 `项目架构.md`。

## 新主线目录

`七参数_MLP_CNN流场重建/`

## 核心脚本

| 文件 | 作用 |
|---|---|
| `01_构建流场数据集.py` | 读取七参数标签和 CFD 全场 npz，构建 MLP-CNN 训练数据集；支持逐工况标准 npz 输出。 |
| `02_MLP_CNN流场重建训练.py` | 训练七参数到 u/v/p/T 场和 Nu/f 的多任务代理模型。 |
| `03_DE优化eta.py` | 加载训练好的模型，用性能分支进行差分进化优化 eta。 |
| `04_准备CFD复算输入.py` | 将 DE 最优参数转换为旧 COMSOL 复算脚本可读取的输入。 |
| `05_生成论文答辩PPT.py` | 根据当前真实结果生成答辩 PPT。 |

## 数据目录

| 路径 | 内容 |
|---|---|
| `data/field_reconstruction_dataset_full.npz` | 1000 组统一网格流热场训练数据。 |
| `data/dataset_summary.json` | 数据集摘要。 |
| `data/standard_case_npz_check/` | 逐工况标准格式样例，字段为 `params, U, V, p, T, Nu, f, eta`。 |

## 结果目录

| 路径 | 内容 |
|---|---|
| `results/mlp_cnn_field_multiloss_e10/` | 新版多任务损失 MLP-CNN 训练结果。 |
| `optimization_results/mlp_cnn_de_multiloss_e10/` | DE 优化结果。 |
| `cfd_validation_inputs/mlp_cnn_de_multiloss_e10/` | CFD 复算输入。 |
| `validation_results/mlp_cnn_de_multiloss_e10/` | 二维 CFD 复算结果和云图。 |

## 论文表述边界

- 最终主线不再写成几何掩码。
- 几何掩码最多作为旧方案或对照讨论。
- CFD 云图和数值场是监督标签，不是模型输入。
- CNN 的作用是将七参数编码得到的潜在特征解码为空间流热场。
- 三维结果写成迁移验证，不能写成三维全局优化。
