# 网格无关性补算执行清单

本文档用于把当前“网格无关性未通过”的问题转成可执行补算任务。它不修改既有实验结论，也不把未通过结果写成通过结果。

## 1. 当前失败证据

当前正式审计结论为：网格无关性未通过，不能标记整套论文目标完成。

二维局部尺寸 G3/G4/G5 真实补算结果：

- baseline：G4/G5 的 `Nu` 相对误差为 `21.070%`，`f` 相对误差为 `14.329%`。
- DE_optimum：G4/G5 的 `Nu` 相对误差为 `16.006%`，`f` 相对误差为 `11.730%`。
- 判据：二维 `Nu <= 2%`，`f <= 3%`，因此二维未通过。

三维 coarse/medium/fine 真实补算结果：

- baseline：medium/fine 的 `Tmax` 相对误差为 `0.632%`，`pressure_drop` 相对误差为 `13.385%`。
- optimized：medium/fine 的 `Tmax` 相对误差为 `0.315%`，`pressure_drop` 相对误差为 `8.063%`。
- 判据：三维 `Tmax <= 1%`，`pressure_drop <= 5%`，因此三维温度通过、压降未通过。

## 2. 优先级判断

优先级 1：二维壁面、尾迹和压降后处理的一致性。

原因：二维 Nu/f 误差远超阈值，且两组工况都随网格细化单调变化，说明当前局部网格仍未达到稳定积分结果。

优先级 2：三维压降后处理截面和局部网格。

原因：三维 Tmax 已满足阈值，主要风险集中在压降。若压降截面、入口出口平均压力和局部速度梯度控制不一致，pressure_drop 会明显受网格影响。

优先级 3：论文表达边界。

原因：在新补算未通过前，论文只能写“已开展网格敏感性补算并发现网格风险”，不能写“网格无关性通过”。

- 出口边界是否固定为同一几何边界。

## 4. 三维补算任务

### 4.1 必须确认的后处理

在三维脚本中继续检查：

- `p_in_avg_pa` 和 `p_out_avg_pa` 是否来自固定入口/出口截面。
- `delta_p_pa = p_in_avg_pa - p_out_avg_pa` 是否没有混入局部点值。
- 每个网格档位是否使用同一流量、入口温度、热源功率、材料属性和外壁条件。
- 三维导出结果中必须同时保留 `p_in_avg_pa`、`p_out_avg_pa`、`delta_p_pa`，不能只保留差值。
