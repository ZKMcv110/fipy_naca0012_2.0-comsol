# 项目架构：MLP-CNN 流热场重建主线隔离版

本文件是新目录内的隔离版项目架构说明。按用户要求，未覆盖根目录 `项目架构.md`。

当前论文主线：

> 基于 MLP-CNN 流热场重建代理模型的翼型柱阵列散热器优化研究

核心流程：

```text
七参数参数化建模
-> 二维 CFD 流热耦合仿真
-> 导出 Nu、f、eta 以及 u/v/p/T 数值场
-> 统一网格化构建多通道流热场数据集
-> 建立 MLP-CNN 流热场重建代理模型
-> 输入七参数，预测 u/v/p/T 场和 Nu/f
-> 由 Nu/f 计算 eta
-> 采用 DE 搜索 eta 最大的结构参数组合
-> CFD 复算验证最优结构
-> 对比速度场、压力场、温度场
-> 三维散热器迁移验证
```

核心交付物：

| 类型 | 路径 |
|---|---|
| 数据集构建 | `01_构建流场数据集.py` |
| 模型训练 | `02_MLP_CNN流场重建训练.py` |
| DE 优化 | `03_DE优化eta.py` |
| CFD 复算输入 | `04_准备CFD复算输入.py` |
| PPT 生成 | `05_生成论文答辩PPT.py` |
| 最终证据链 | `最终验收清单.md` |
| 方法章节 | `论文方法章节草稿.md` |
| 实验章节 | `论文实验章节草稿.md` |
| 答辩 PPT | `MLP_CNN流热场重建_论文答辩PPT.pptx` |

当前结论边界：

- 最终主线不再使用几何掩码作为核心创新点。
- CFD 云图和数值场是监督标签，不是模型输入。
- CNN 的作用是由七参数潜在特征解码预测空间流热场。
- 旧 1000 组 ANN/MLP 结果保留为 baseline 对照，不删除。
- 三维结果写作迁移验证，不写作三维全局最优。
