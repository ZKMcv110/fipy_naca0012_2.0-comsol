# 论文方法章节草稿：MLP-CNN 流热场重建代理模型

## 方法总述

本文以七参数参数化翼型柱阵列散热器为研究对象，首先通过二维 CFD 流热耦合仿真获得结构参数、综合性能指标和流热场数值数据。随后将不同工况的速度场、压力场和温度场统一到规则网格上，构建多通道流热场数据集。在此基础上，建立 MLP-CNN 多任务代理模型，实现由七参数到流热场及散热性能指标的快速预测。最后以综合性能指标 eta 为目标，采用差分进化算法搜索最优结构，并通过 CFD 复算验证代理模型优化结果。

## 七参数输入

输入参数向量定义为：

```text
x = [Ta, Twa, Tb, Ts, Tt, Tad, theta]
```

七参数共同控制翼型柱阵列的形状、尺度、间距和角度。所有参数在训练前进行标准化处理，以降低量纲差异对网络训练的影响。

## 流热场数据构建

每个样本由结构参数、性能标签和流热场标签组成。场数据来自 CFD 求解后的数值结果，而不是由图片反推得到。统一后的单个工况数据格式为：

```text
params: 7 维参数
U: 50 x 80
V: 50 x 80
p: 50 x 80
T: 50 x 80
Nu, f, eta
```

其中 `U` 和 `V` 表示速度分量，`p` 表示压力场，`T` 表示温度场。模型训练时使用四通道场数据 `u/v/p/T` 作为监督标签。

综合性能指标 eta 定义为：

```text
eta = (Nu / Nu0) / (f / f0)^(1/3)
```

其中 `Nu0` 和 `f0` 为基准结构的努塞尔数和摩擦因子。

## MLP-CNN 代理模型结构

模型由三部分组成：

1. MLP Encoder：输入七参数，输出高维潜在特征。
2. CNN Decoder：将潜在特征上采样并卷积解码为 `u/v/p/T` 四通道空间场。
3. MLP Head：基于共享潜在特征预测 `Nu` 和 `f`。

网络结构可表示为：

```text
七参数 -> MLP Encoder -> 潜在特征 z
z -> CNN Decoder -> u/v/p/T
z -> MLP Head -> Nu/f -> eta
```

需要强调的是，CFD 云图和场数据不是模型输入，而是监督标签。CNN 的作用不是识别图像，而是从参数潜在特征中恢复流热场的空间分布，使代理模型同时具备性能预测能力和物理可解释性。

## 损失函数

训练采用多任务损失函数：

```text
L = L_u + L_v + L_p + L_T + alpha * L_Nu + beta * L_f + gamma * L_eta
```

其中，`L_u`、`L_v`、`L_p` 和 `L_T` 分别约束速度、压力和温度场重建误差；`L_Nu` 和 `L_f` 约束性能指标预测误差；`L_eta` 约束综合性能指标误差。当前实验取：

```text
alpha = 1.0
beta = 1.0
gamma = 0.2
```

eta 不作为独立网络输出，而是由预测得到的 `Nu` 和 `f` 按公式计算得到。这样可以保证综合指标与基础性能指标之间保持物理一致性。

## 物理一致性约束与注意力机制设计

当前实证模型中，物理一致性主要体现在两方面：第一，网络直接重建 `u/v/p/T` 数值场，使潜在特征受到流热场空间分布监督；第二，加入 `L_eta` 指标一致性损失，使预测得到的 `Nu`、`f` 与综合性能指标 eta 保持定义一致。

进一步地，模型可以扩展为包含 PDE 辅助约束的形式：

```text
L_total = L_field + alpha*L_Nu + beta*L_f + gamma*L_eta
          + lambda1*L_cont + lambda2*L_energy + lambda3*L_bc
```

其中，`L_cont` 表示连续性约束，`L_energy` 表示能量方程或温度场平滑残差，`L_bc` 表示入口、出口、壁面和流固界面的边界一致性约束。需要说明的是，当前论文的主要实证结果来自 MLP-CNN 多任务损失和 eta 一致性约束，完整 PDE 残差项作为可扩展物理增强模块给出，不作为已经完成的核心实验结论。

注意力机制方面，旧路线中已有 CBAM/PI-CNN-CBAM 相关实现和结果，但其输入形式属于几何掩码或物理场图像路线。对于当前 MLP-CNN 流热场重建主线，注意力模块更适合插入 CNN Decoder 中，用于增强关键通道和局部空间响应。例如，可在解码器中加入 SE 或 CBAM 模块，对 `u/v/p/T` 四通道特征进行通道重标定，并在尾迹、热边界层和压力梯度较大的区域增强空间响应。本文将该机制作为模型扩展与消融设计讨论，不将旧几何掩码注意力结果直接等同于当前主模型结果。

## 参数敏感性分析方法

为解释七参数对性能指标的影响，本文在当前 1000 组 CFD 样本和训练后的 MLP-CNN 代理模型基础上进行参数敏感性分析。分析包括三类：

1. Pearson/Spearman 相关性，用于描述参数与 `Nu`、`f`、`eta` 的线性和秩相关关系；
2. 随机森林特征重要性，用于估计七参数对性能指标的全局统计贡献；
3. DE 最优点附近的单参数局部扰动，用当前 MLP-CNN 代理模型预测 eta 变化范围。

该敏感性分析属于数据驱动统计分析和代理模型局部响应分析，不能替代固定其余参数的严格 CFD 单因素扫描。

## 差分进化优化

训练完成后，固定 MLP-CNN 模型参数，使用其性能预测分支快速评估候选结构。差分进化算法在七参数设计空间内搜索 eta 最大的参数组合。优化结果不直接作为最终结论，而是作为 CFD 复算候选结构。

## CFD 复算与三维迁移验证

对 DE 得到的最优七参数重新建立 CFD 模型并求解，导出 `Nu`、`f`、`eta`、压降、温差以及速度场、压力场和温度场。二维 CFD 复算用于验证代理模型优化结果。三维芯片级散热器模型用于迁移验证，说明二维优化候选在更接近工程结构的三维模型中是否仍具有收益。三维验证不表述为三维全局最优。
