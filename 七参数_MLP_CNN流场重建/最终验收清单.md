# MLP-CNN 流热场重建主线最终验收清单

## 1. 当前论文主线

论文主线统一为：

> 基于 MLP-CNN 流热场重建代理模型的翼型柱阵列散热器优化研究

技术路线：

七参数参数化建模 -> 二维 CFD 流热耦合仿真 -> 导出 Nu、f、eta 与 u/v/p/T 数值场 -> 统一网格化构建多通道流热场数据集 -> 建立 MLP-CNN 流热场重建代理模型 -> DE 优化 eta -> CFD 复算验证 -> 三维散热器迁移验证。

说明：

- 不再把“几何掩码”作为最终主线。
- CFD 云图和数值场不是模型输入，而是监督标签。
- CNN 的作用是从七参数潜在特征中解码预测 u/v/p/T 空间场。

- 七参数与 Nu/f 标签：`七参数_几何掩码代理优化/samples/labels_7param_1000.csv`

## 3. 模型与训练

训练脚本：

- `02_MLP_CNN流场重建训练.py`

模型结构：

```text
七参数 -> MLP Encoder -> 潜在特征 z
潜在特征 z -> CNN Decoder -> u/v/p/T
潜在特征 z -> MLP Head -> Nu/f -> eta
```

损失函数：

```text
L = L_u + L_v + L_p + L_T + alpha * L_Nu + beta * L_f + gamma * L_eta
```

## 8. 复现命令

构建数据集：

```powershell
python "七参数_MLP_CNN流场重建\01_构建流场数据集.py" --output "七参数_MLP_CNN流场重建\data\field_reconstruction_dataset_full.npz"
```

训练模型：

```powershell
python "七参数_MLP_CNN流场重建\02_MLP_CNN流场重建训练.py" --dataset "七参数_MLP_CNN流场重建\data\field_reconstruction_dataset_full.npz" --epochs 10 --batch-size 64 --output-dir "七参数_MLP_CNN流场重建\results\mlp_cnn_field_multiloss_e10"
```

DE 优化：

```powershell
python "七参数_MLP_CNN流场重建\03_DE优化eta.py" --model-dir "七参数_MLP_CNN流场重建\results\mlp_cnn_field_multiloss_e10" --generations 30 --pop-size 40 --output-dir "七参数_MLP_CNN流场重建\optimization_results\mlp_cnn_de_multiloss_e10"
```

准备 CFD 复算输入：

```powershell
python "七参数_MLP_CNN流场重建\04_准备CFD复算输入.py" --best "七参数_MLP_CNN流场重建\optimization_results\mlp_cnn_de_multiloss_e10\best_params.json" --output-dir "七参数_MLP_CNN流场重建\cfd_validation_inputs\mlp_cnn_de_multiloss_e10" --validation-dir "七参数_MLP_CNN流场重建\validation_results\mlp_cnn_de_multiloss_e10"
```
