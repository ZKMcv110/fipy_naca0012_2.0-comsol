# 数据说明

本文档说明当前二维 CFD 数据、神经网络输入输出和三维结果文件的来源与用途。

## 1. 二维 CFD 数据集

主目录：

```text
consol_cfddata/
```

统一标签：

```text
consol_cfddata/labels.csv
```

## 2. 每个二维工况目录

命名格式：

```text
consol_cfddata/case_{case_id}_cfd_solution/
```

正式工况至少包含：

| 文件 | 用途 |
|---|---|
| `model.mph` | COMSOL 二维模型 |
| `result.json` | 单工况参数、物理结果和衍生量 |
| `velocity_magnitude.png` | 速度场图像，神经网络图像输入之一 |
| `pressure.png` | 压力场图像，神经网络图像输入之一 |
| `temperature.png` | 温度场图像，神经网络图像输入之一 |

`labels.csv` 是训练脚本默认使用的统一标签源。`result.json` 是单工况追溯源。

## 3. 神经网络输入

多模态 CNN 输入由两部分组成：

1. 图像输入：
   - `velocity_magnitude.png`
   - `pressure.png`
   - `temperature.png`
2. 标量输入：
   - `Ta`
   - `Twa`
   - `Tb`
   - `Ts`
   - `Tt`
   - `Tad`

输出目标：

- `Nu`
- `f`

PI-CNN-CBAM 额外使用：

```text
consol_cfddata/field_data_npz/
```

该目录提供温度场网格和掩膜，用于辅助场重构损失和物理约束损失。

## 5. 三维结果

三维代表性热沉结果目录：

```text
comsol_3d_airfoil_radiator/generated_pillar_heat_sink/results/
```

主要文件：

| 文件 | 用途 |
|---|---|
| `pillar_heat_sink_summary.csv` | 三维结果表 |
| `pillar_heat_sink_summary.json` | 三维结果结构化文件 |
| `pillar_heat_sink_summary.md` | 三维结果 Markdown 表，目前存在编码显示问题 |

当前三维结果显示 `optimal` 和 `optimal_2d` 相对 `baseline` 的优势不明显。论文中应按“代表性三维验证/迁移效果有限”表述，不应写成“三维全局最优”。

## 6. 数据使用原则

- 训练、评价和论文表格优先使用 `labels.csv`、模型指标 JSON/CSV 和三维 summary 文件。
- 云图只能证明可视现象，不能替代表格指标。
- `Q_total` 在二维中作为辅助能量指标，不作为主要散热性能直观指标。
- 二维和三维边界条件、热源形式、评价指标不同，结论必须分开写。
