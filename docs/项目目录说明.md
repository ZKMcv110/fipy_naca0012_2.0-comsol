# 项目目录说明

本文档用于说明当前项目目录的职责边界，避免误删数据、误移脚本或把旧六参数结果混入当前七参数论文主线。当前目录审查结论见 `docs/项目目录当前审查.md`，更详细的整理和归档方案见 `docs/项目目录整理方案.md`。

## 当前论文主线

当前论文主线是七参数 MLP-CNN / Conditional U-Net 流热场重建代理模型，不再以旧六参数 CNN、旧几何掩码或旧云图输入模型作为最终主线。

主线流程为：

```text
七参数参数化建模
-> 二维 CFD 流热耦合仿真
-> p/U/T 高分辨率 PVT 流热场数据集
-> MLP-CNN / Conditional U-Net 流热场重建代理模型
-> Nu、f、eta 预测
-> 差分进化 DE 优化 eta
-> 二维 CFD 复算验证
-> 三维芯片散热器迁移验证
```
