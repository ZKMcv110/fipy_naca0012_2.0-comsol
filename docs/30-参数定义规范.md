# 参数定义规范

七参数几何参数化的唯一权威定义。论文符号表、代码常量、答辩问答一律以本文为准。
数据来源：`七参数_MLP_CNN流场重建/03_DE优化eta.py`、`工具脚本/comsol单次执行脚本.py`、`工具脚本/consol500组参数.py` 实际代码，非推测。

## 1. 参数总表

| 符号 | 物理含义 | 单位 | 取值范围 | 基线值 | 作用对象 |
|---|---|---|---|---|---|
| `Ta` | 翼型最大相对弯度（NACA 弯度线幅值） | 无量纲（×弦长） | 0.00 – 0.05 | 0.00 | 单柱翼型形状 |
| `Twa` | 最大弯度位置（NACA 第二位含义） | 无量纲（×弦长） | 0.20 – 0.60 | 0.40 | 单柱翼型形状 |
| `Tb` | 翼型相对厚度（NACA 厚度分布系数） | 无量纲（×弦长） | 0.08 – 0.15 | 0.12 | 单柱翼型形状 |
| `Ts` | 流向（x 向）列间距系数 | 无量纲（×弦长） | 0.50 – 1.50 | 1.10 | 阵列排布 |
| `Tt` | 展向（y 向）排间距系数 | 无量纲（×弦长） | 0.50 – 1.20 | 0.85 | 阵列排布 |
| `Tad` | 错列量（奇数列沿 x 的偏移量） | 无量纲（×弦长） | 0.00 – 1.00 | 0.00 | 阵列排布 |
| `theta` | 攻角 | 度（°） | −10.0 – 10.0 | 0.0 | 单柱姿态 |

基线值即 NACA 0012 正对称翼型的规则阵列：`Ta=0`（无弯度）、`Tb=0.12`（12% 相对厚度，即项目名称中 0012 的来源）、`Tad=0`（不错列）、`theta=0`（零攻角）。

## 2. 几何语义

### 2.1 翼型型线（NACA 四位参数化）

以归一化弦向坐标 `s ∈ [0,1]` 表示，中弧线 `yc` 与半厚度 `yt` 为：

```
yt(s) = (Tb / 0.2) · (0.2969√s − 0.1260s − 0.3516s² + 0.2843s³ − 0.1036s⁴)

yc(s) = s < Twa :  Ta/Twa²  · (2·Twa·s − s²)
        s ≥ Twa :  Ta/(1−Twa)² · ((1−2·Twa) + 2·Twa·s − s²)
```

上、下型线由中弧线倾角 `θ(s) = atan(dyc/ds)` 生成：

```
xu = (s − yt·sinθ)·chord      yu = (yc + yt·cosθ)·chord
xl = (s + yt·sinθ)·chord      yl = (yc − yt·cosθ)·chord
```

### 2.2 阵列排布

阵列规模 **3 排 × 8 列 = 24 个翼型柱**（`y_factors = [-1, 0, 1]`，`i = 0..7`）。

第 j 排第 i 列柱体的平移量：

```
Δx = i · (1 + Ts) · chord + (j 为奇数 ? Tad · chord : 0)
Δy = y_factors[j] · Tt · chord
```

注意 `Ts` 的实际列距是 **(1 + Ts) 倍弦长**，不是 Ts 倍；`Tad` 只对奇数列生效（j=1），形成错列。

### 2.3 流道尺寸

```
流道宽 W = (8·(1 + Ts) + Tad + 15) · chord
流道高 H = 2 · (Tt + Ta + Tb + 0.35) · chord
```

流道高随 `Tt`、`Ta`、`Tb` 联动，保证上下留 0.35 倍弦长余量；流道以 y 向居中布置（左下角 y = −(Tt+Ta+Tb+0.35)·chord）。

## 3. 固定常量

| 常量 | 值 | 说明 |
|---|---|---|
| `chord` | 0.01 m（10 mm） | 弦长，全部几何量的基准尺度 |
| `u_in` | 5 m/s | 入口速度 |
| `T_amb` | 293.15 K | 环境温度 |
| `Q_heat` | 由命令行传入 | 体热源强度 |
| 阵列 | 3 × 8 | 排数 × 列数 |

## 4. 目标函数

综合评价因子 `eta`（强化换热性能指标，即 PEC）：

```
eta = (Nu / Nu0) / (f / f0)^(1/3)
```

其中 `Nu0`、`f0` 为基线结构（最接近原始结构的样本）的努塞尔数与摩擦因子。差分进化 DE 在七维参数空间内搜索 `eta` 最大值。

## 5. 必须注意的两处命名陷阱

1. **`theta` 同名不同义。** 建模脚本 `工具脚本/comsol单次执行脚本.py` 内部有一个解析函数也命名为 `theta`，其含义是中弧线倾角 `atan(dyc(s))`（随 s 变化的内部量）；而第七个参数 `theta` 是**攻角**（标量，度）。二者仅同名，读代码时勿混淆。
2. **`Ts` 的实际间距是 `1 + Ts` 倍弦长。** 论文写间距时若直接写 `Ts·chord` 会少一个弦长。

## 6. 参数演进

- **六参数阶段**：`consol500组参数.py` 的 `PARAM_BOUNDS` 只含 6 个参数（无 `theta`），500 组样本在 6 维空间拉丁超立方采样（seed=42）。
- **七参数阶段**：新增攻角 `theta ∈ [−10, 10]`，`PARAM_RANGES` 定义在 `03_DE优化eta.py`。当前 500 组 / 1000 组 CFD 数据集仍是**六参数**采样结果，`theta` 维度在代理模型阶段引入。

此差异影响论文表述：**CFD 样本集不含攻角变化**，若论文中声称"七参数数据集"，需核对实际数据文件是否覆盖 theta 维度。

## 7. 归一化

参数按 `PARAM_RANGES` 的上下界做 min-max 归一化到 [0, 1] 后输入 MLP 编码器（输入维度 7）。
场数据（p/U/T）为独立通道，见 `data/field_reconstruction_dataset_320x96_full_pUt.npz`。
