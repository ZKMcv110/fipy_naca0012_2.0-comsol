## ADR-001 求解器由 FiPy 迁移至 COMSOL Multiphysics

**背景**：项目初始（`3b32769f` 及之前）用 FiPy 做二维流热耦合求解，目录 `fipy_pipeline/`。

**决策**：迁移到 COMSOL Multiphysics 6.3，通过 MPh 1.3.1 以 Python 脚本驱动建模与求解。

**依据**：
- **核心原因：FiPy 在二维流热耦合问题上求解无法收敛。** 该项目同时包含阵列绕流（非线性对流项）与流固共轭传热（两域温度耦合），FiPy 的迭代求解在此耦合强度下残差不下降，得不到可用解。（作者确认，2026-09-05）
- **批量要求放大了收敛性问题**：项目需要 500 / 1000 组参数化样本，求解器必须在任意参数组合下都稳定收敛。FiPy 的收敛性依赖逐例调参（松弛因子、时间步、网格），无法支撑无人值守的批量扫描。
- COMSOL 提供成熟的共轭传热物理场接口、自动网格与稳健的稳态/瞬态非线性求解器，由 MPh 脚本驱动后可在无人干预下批量出解。
- git 提交 `8ec5e843`：`大重构：从 FiPy 迁移至 COMSOL/CNN 流程，整理项目结构`。
- 当前全部 CFD 数据集（500 组 / 1000 组）均由 COMSOL 生成，`.mph` 文件保留可作追溯。

**影响**：
- 求解依赖商业许可，换机需重新授权（唯一无法自动化的复现环节）。
- 物理场配置在 `工具脚本/comsol单次执行脚本.py`，含 NACA 解析型线与阵列排布。
- 旧 FiPy 流程归档保留，不作当前入口。

**状态**：已采纳并执行。旧流程仅作追溯。

## ADR-002 参数空间由六维扩展至七维（新增攻角 theta）

**背景**：500 组 / 1000 组 CFD 样本集在六维参数空间采样。

**决策**：新增第七维攻角 `theta ∈ [−10°, 10°]`，基线 0°。

**依据**：
- `工具脚本/consol500组参数.py` 的 `PARAM_BOUNDS` 仅含 6 个参数，无 theta。
- `七参数_MLP_CNN流场重建/03_DE优化eta.py` 的 `PARAM_RANGES` 已含 7 个参数。

**影响与风险**：
- **现有 CFD 数据集不含攻角维度**。若论文表述为"七参数数据集"，需核对数据文件是否真覆盖 theta；否则应写作"六参数采样 + 七参数代理模型/优化空间"。
- 参数定义详见 [`参数定义规范.md`](30-参数定义规范.md)。

**状态**：已采纳。数据集与参数空间的维度差需作者在论文中明确处理。

## ADR-003 终止 PDE-PINN 路线

**背景**：`七参数_PDE_PINN尝试/GOAL.md` 提出用 PDE 残差 PINN 直接求解二维稳态不可压层流与共轭传热，目标是 `T R² > 0.95`、`u R² > 0.90`。

**决策**：探索终止，不作为论文方法主线。

**依据（实测数据，来自 `results/single_case_20001/best_config.json`）**：

| 场变量 | 目标 R² | 实测 R² | 实测 RMSE |
|---|---|---|---|
| u | > 0.90 | **0.0028** | 1.395 |
| v | — | **−0.0147** | 0.238 |
| p | — | 0.663 | 7.155 |
| T | > 0.95 | **0.333** | 5.486 |

关键证据：最终最佳配置中 **PDE 残差权重全部为 0**（`continuity/momentum/energy_air/energy_solid = 0.0`），只剩数据监督项。这意味着 PDE 约束在训练中实际被关闭——PINN 已退化为纯数据驱动拟合，且拟合效果远低于目标。

**为什么没继续**：
- Task 1（全场数据导出）已完成：`field_data/` 1000 个 npz，`field_data_320x96/` 另有一批。
- Task 2（单工况）完成但指标不达标。
- Task 3（多参数 PDE-PINN）脚本未创建，路线在此停止。
- `extract_320x96_full.err` 留有参数解析错误（`--ny` 未被识别），第二次数据导出未正常完成。

**影响**：
- 该目录保留作"已验证不可行"的证据，论文中可作为方法对比的负面结果，但**不能**写成已实现的 PINN 方法。
- 数据驱动路线（MLP-CNN / U-Net）继续作为主线。

**状态**：已终止。**建议作者在论文或答辩中保留这张指标表**，"试过 PINN 并给出失败数据"比回避该问题更有说服力。

## ADR-004 论文主线由几何掩码切换为 PVT 流热场重建

**背景**：存在两条七参数代理模型路线。
- 几何掩码路线（`七参数_几何掩码代理优化/`）：七参数 + 几何掩码图 → Nu/f/eta。
- PVT 路线（`七参数_MLP_CNN流场重建/`）：七参数 → 重建 p/U/T 场 + 预测 Nu/f → 计算 eta。

**决策**：PVT 流热场重建作为当前论文主线，几何掩码降为旧主线。

**依据**（`docs/10-项目说明书.md` 14.4）：
1. 几何掩码用于结构到 `Nu/f/eta` 的代理预测。
2. PVT 用于七参数到场（压力、速度、温度）的重建，更能体现 CNN 的作用。
3. 当前论文更适合把 PVT 流热场重建作为主线。

**影响**：
- 论文主线脚本入口以 `七参数_MLP_CNN流场重建/01~21_*.py` 为准。
- 几何掩码目录保留，其 1000 组 baseline 结果仍可引用。
- 差分进化只调用代理模型，不直接调用 COMSOL；COMSOL 仅用于样本生成与最终复核。

**状态**：已采纳并执行。

## ADR-005 三维验证结论的写作边界

**背景**：二维优化结构需向三维芯片级散热器迁移验证（`comsol_3d_airfoil_radiator/`）。

**决策**：三维结果**不得**表述为"已验证三维显著最优"。

**依据**（`README.md` 明确记载）：当前三维结果显示优化结构优势不明显。

**影响**：
- 论文中三维部分应写成"二维优化结构的三维迁移验证"或"趋势一致但优势不显著"，并给出实际数值。
- 三维结果位置：`comsol_3d_airfoil_radiator/generated_pillar_heat_sink/results/` 及各 `seven_param_3d_summary.md`。
- 已完成的网格无关性验证可支撑结论可信度。

**状态**：已采纳。**这是学术诚信红线，任何自动生成论文文字的环节都必须遵守。**
