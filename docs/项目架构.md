10. 三维 Nu/f 定义：
   Nu3D = h_eq * D_h / k_air，其中 h_eq = Q / (A_chip * (T_chip_avg - T_in))。
   f3D = Δp * D_h / (0.5 * rho_air * U0^2 * L_channel)。
   这是三维等效指标，用于和二维 Nu/f 叙述保持一致；原始热阻和压降仍必须同时报告。
