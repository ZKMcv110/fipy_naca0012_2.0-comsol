# 运行入口说明

本文档只记录当前项目可复用的主流程入口。路径以项目根目录 `f:\pyProject\fipy_naca0012_2.0` 为准。

## 1. 当前七参数论文主线入口

当前论文主线为七参数 PVT 流热场重建，不再以旧六参数 CNN 或旧几何掩码流程作为最终主线。

核心目录：

- `七参数_MLP_CNN流场重建/`：PVT 数据集、Conditional U-Net、K 折、消融、敏感性、DE、二维 CFD 复算、证据链。
- `七参数_几何掩码代理优化/`：七参数早期几何掩码代理、COMSOL 批量求解和二维单工况脚本。
- `七参数_PDE_PINN尝试/`：p/U/T 场数据来源和 PDE/PINN 探索。
- `comsol_3d_airfoil_radiator/`：三维芯片级散热器建模、后处理和迁移验证。

主线证据入口：

```powershell
python "七参数_MLP_CNN流场重建/16_论文证据链汇总.py"
```

## 2. 旧六参数二维 COMSOL 数据生成

单工况运行：

```powershell
python 工具脚本/comsol单次执行脚本.py --Ta 0 --Twa 0.4 --Tb 0.12 --Ts 1.1 --Tt 0.85 --Tad 0 --outdir consol_cfddata/case_test_cfd_solution
```

批量生成指定数量样本：

```powershell
python 工具脚本/consol500组参数.py --num-samples 500
```

当前二维数据位置：

- 标签文件：`consol_cfddata/labels.csv`
- 每个工况：`consol_cfddata/case_{编号}_cfd_solution/`
- 每个工况至少应包含：`model.mph`、`result.json`、`velocity_magnitude.png`、`pressure.png`、`temperature.png`

## 3. 旧六参数神经网络训练与预测

当前神经网络脚本集中在 `旧六参数流程/模型脚本/`。

旧六参数入口仍保留，避免历史命令失效：

```powershell
python cnnstep1.py
python cnnstep2.py
python cnnstep3.py --case-id 1
```

其中 `cnnstep1.py` 兼容导出旧模型定义，`cnnstep2.py` 转到 `旧六参数流程/模型脚本/CNN_CBAM_训练.py`，`cnnstep3.py` 转到 `旧六参数流程/模型脚本/CNN_CBAM_预测.py`。新开发和论文复现实验优先使用下列整理后的脚本路径。

MLP 基线：

```powershell
python 旧六参数流程/模型脚本/MLP基线_训练.py
```

传统特征融合模型：

```powershell
python 旧六参数流程/模型脚本/多模态特征融合_训练.py
```

CNN+CBAM+GAP：

```powershell
python 旧六参数流程/模型脚本/CNN_CBAM_训练.py
python 旧六参数流程/模型脚本/CNN_CBAM_预测.py --case-id 1
```

PI-CNN-CBAM：

```powershell
python 旧六参数流程/模型脚本/物理信息CNN_训练.py
python 旧六参数流程/模型脚本/物理信息CNN_预测.py --case-id 1
```

默认依赖：

- 标签：`consol_cfddata/labels.csv`
- 图像数据：`consol_cfddata/case_{编号}_cfd_solution/`
- 数据划分：`ai_cnn_model_results/dataset_split.csv`
- PI-CNN 辅助场数据：`consol_cfddata/field_data_npz/`

旧六参数历史结果已归档到 `归档/旧六参数模型结果/`。如果重新运行本节旧训练脚本，脚本可能按原逻辑在根目录重新生成 `ai_cnn_model_results/`、`cnn_big_results/`、`cnn_cbam_gap_results/` 或 `pi_cnn_nuf_results/`。

## 4. 三维 COMSOL 模型

三维主流程在 `comsol_3d_airfoil_radiator/`。

七参数论文当前采用的三维代表性芯片散热器流程如下：

```powershell
python "comsol_3d_airfoil_radiator/13_七参数真实芯片散热器建模.py" --case-name pi_cbam_best --mesh-hauto 8 --solve
python "comsol_3d_airfoil_radiator/14_导出七参数三维结果图.py"
python "comsol_3d_airfoil_radiator/15_提取七参数三维指标.py"
```

当前七参数三维论文结果位置：

- 结果表：`comsol_3d_airfoil_radiator/generated_7param_chip_heat_sink/results/seven_param_3d_summary.csv`
- 结果说明：`comsol_3d_airfoil_radiator/generated_7param_chip_heat_sink/results/seven_param_3d_summary.md`
- 图像输出：`comsol_3d_airfoil_radiator/generated_7param_chip_heat_sink/pi_cbam_best/exports/`

注意：该三维流程用于代表性工程复核，不是三维全局优化。论文中不能把二维代理优化结果写成三维最优结构。

生成并求解基准、保守交错、二维最优三维化三组模型：

```powershell
python comsol_3d_airfoil_radiator/build_airfoil_pillar_heat_sink.py --all --mesh-hauto 4 --solve
```

只生成自定义参数模型：

```powershell
python comsol_3d_airfoil_radiator/build_airfoil_pillar_heat_sink.py --case custom --case-name my_case --Ta 0.0473 --Twa 0.3735 --Tb 0.0917 --Ts 1.3541 --Tt 1.0926 --Tad 0.3950 --mesh-hauto 4
```

构建新的真实感三维热沉模型：

```powershell
python comsol_3d_airfoil_radiator/build_realistic_airfoil_heat_sink.py --case baseline --skip-mesh
python comsol_3d_airfoil_radiator/build_realistic_airfoil_heat_sink.py --case optimal_2d --skip-mesh
```

求解新模型：

```powershell
python comsol_3d_airfoil_radiator/build_realistic_airfoil_heat_sink.py --all --mesh-hauto 5 --solve
```

后处理三维结果：

```powershell
python comsol_3d_airfoil_radiator/05_结果后处理.py
python comsol_3d_airfoil_radiator/10_绘制结果汇总.py
```

当前三维结果汇总：

- `comsol_3d_airfoil_radiator/generated_pillar_heat_sink/results/pillar_heat_sink_summary.csv`
- `comsol_3d_airfoil_radiator/generated_pillar_heat_sink/results/pillar_heat_sink_summary.json`

## 5. 目录使用规则

- 原始 CFD 数据、`.mph`、训练权重和结果文件默认不移动、不删除。
- 根目录只保留主入口脚本、项目说明和必要配置。
- 临时日志放入 `归档/`；COMSOL 探查脚本放入 `工具脚本/`；外部案例资料放入 `paper_reference/参考资料/`。
- 提交 Git 前先检查 `git status --short`，重点确认旧脚本删除和 `旧六参数流程/模型脚本/` 新脚本是否是预期迁移。
