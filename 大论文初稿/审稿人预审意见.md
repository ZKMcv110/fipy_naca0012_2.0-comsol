# 大论文初稿审稿人预审意见

审查对象：`大论文初稿/完整论文初稿.md`

审查结论：建议按“大修后再提交”标准处理。当前稿件已经形成完整主线，图表占位和K折交叉验证缺失等早期问题已明显改善；但仍存在三类核心风险：一是部分图注和正文仍带有“计划式写法”；二是二维优化有效与三维迁移不显著之间的结论边界需要继续收紧；三是参数量纲、采样方法和模型名称需要与真实代码和数据保持完全一致。

## 1. 主要问题

### 1.1 三维验证不支持“工程性能明显提升”的强结论

第5章表5-5显示，二维最优三维化结构相对基准结构的芯片平均温度和等效热阻并未降低：

- 基准结构：`T_chip,avg = 388.663 K`，`R_th = 95.513 K/W`，`η_3D = 1.000`。
- 二维最优三维化结构：`T_chip,avg = 388.926 K`，`R_th = 95.776 K/W`，`η_3D = 1.000`。

因此，第5章和结论中不能写成“三维模型验证了优化结构散热性能提升”。更稳的表述是：二维优化结构在三维代表性热沉模型中保持了相近的流动阻力，但未表现出明显热阻优势，说明二维优化结果向三维工程模型迁移时需要重新建立三维目标函数或三维代理模型。

### 1.2 多模态优化阶段的逻辑仍是审稿重点

第4章已经说明优化阶段采用固定视觉输入策略，而不是为每个候选结构实时生成对应流场图像。这是必要说明，但审稿人会继续追问：优化搜索阶段是否实际退化为“固定图像 + 几何参数”的代理模型。

建议在4.5节进一步强调：多模态图像主要用于训练阶段学习流场空间特征，优化阶段只用于快速筛选，最终性能判断以COMSOL独立复核为准。若后续继续加强，最有说服力的是补充“纯几何MLP优化候选结构”和“多模态融合模型优化候选结构”的复核对比。

### 1.3 参数量纲仍需最终统一

论文中仍使用`T_a、T_wa、T_b、T_s、T_t、T_ad`作为六维参数。若按当前写法保留这些符号，需要明确它们到底是实际尺寸参数、相对弦长比例，还是脚本内部的归一化几何控制量。

当前最稳写法是：正文称其为“参数化几何控制量”，表中增加或保留“量纲/换算关系”说明；COMSOL建模时再由脚本换算为实际几何尺寸。不要同时写“不用无量纲”和“间距为0.50～1.50但没有单位”，否则读者会质疑物理尺寸来源。

### 1.4 部分图仍需替换为真实COMSOL截图或进一步说明

图1-2技术路线图已改为分层SVG，图5-6至图5-8已替换为来自`.mph`结果图组的三维速度、温度和压力场对比图。但图3-3、图3-4等网格图仍偏示意性质，若导师强调“必须能看出真实网格数量和近壁面加密”，建议最终用COMSOL网格截图替换。

另外，当前自动导出的三维COMSOL结果图没有携带COMSOL原生颜色条。若学校或导师要求云图必须带COMSOL色标，需从COMSOL图形窗口勾选图例后手动导出，或继续完善COMSOL导出节点。

### 1.5 文字中仍有少量“计划式”表述

当前全文已无`【图】`、`【表】`占位符，但仍存在一些“应、可、若、建议、正式定稿”等表达。这类文字在方法限制说明中可以保留，但不能出现在结果图说明中。尤其第3章敏感性分析和网格验证部分，应尽量改成“本文采用……结果表明……”，而不是“可采用……应展示……”。

## 2. 次要问题

### 2.1 图4-6a引用已修正，但仍要检查排版

正文中“五折交叉验证结果”已改为引用`fig4_6a_feature_kfold.svg`。后续导出Word或PDF时，需要检查该图的字体、坐标轴和图题是否清晰。

### 2.2 采样方法需要和代码完全一致

论文中如果保留“LHS生成500组样本”，就不要再写“L25正交试验与LHS共同生成500组”，除非代码和数据目录能证明确实是25组正交加475组LHS。采样方法属于可复现性问题，审稿人会追数据来源。

### 2.3 第3章网格部分不要过度声称网格无关性

目前三维部分更像“网格求解稳定性检查”，不是严格网格无关性验证。二维部分若没有多套网格数量对应的Nu、f变化表，也不宜写成严格网格无关性结论。可以写“采用统一网格策略和近壁面加密以保证样本间相对比较一致”。

### 2.4 参考文献格式还需要统一

参考文献部分应统一作者、题名、期刊、年份、卷期页码和DOI格式。机器学习模型、CBAM、差分进化、COMSOL/CFD控制方程相关文献尤其需要补齐。

## 3. 当前最稳的论文主张

建议把全文主张固定为：

本文在二维翼型管阵列模型中建立了参数化CFD样本库，验证了融合几何参数与流场图像特征的多模态模型能够提高Nu和f预测精度，并可辅助二维参数化结构筛选。COMSOL独立复核表明，二维优化结构在二维模型中具有一定综合性能提升；三维代表性模型进一步说明，二维最优结构不能直接等同于三维工程最优结构，后续需要面向三维热阻、压降和真实安装边界重新构建优化目标。

## 4. 下一步最应该处理

优先把全文中剩余“应、可、若、正式定稿”等计划式语句筛出来，逐句判断：已经有真实结果的改成完成式表述；没有真实结果的降级为“局限性”或移到展望。这个比继续增加新图更能提高初稿可信度。
