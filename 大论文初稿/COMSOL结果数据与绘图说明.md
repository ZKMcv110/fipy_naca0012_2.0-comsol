## 4. COMSOL里手动导出数值结果的方法

### 4.1 导出整体指标

1. 打开 `结果`。
2. 右键 `派生值`。
3. 根据指标选择：
   - `全局计算`：用于全局变量、积分算子结果；
   - `表面积分`：用于入口/出口流量、热流；
   - `表面平均`：用于入口/出口平均压力、平均温度；
   - `体平均`：用于芯片平均温度、翼型管平均温度。
4. 表达式示例：
   - 速度大小：`spf.U`
   - 压力：`p`
   - 温度：`T` 或 `ht.T`
   - 入口平均压力：对入口边界做 `p` 的表面平均
   - 出口平均温度：对出口边界做 `T` 的表面平均
5. 点击 `计算`，再从表格右上角导出 CSV。

### 4.2 导出剖面线数据

1. 在 `结果 > 数据集` 中新建 `截线 2D` 或 `截线 3D`。
2. 设置起点和终点，例如：
   - 中心线速度剖面；
   - 出口截面温度剖面；
   - 阵列后方尾迹区温度剖面；
   - 沿主流方向压力剖面。
3. 新建 `一维绘图组`。
4. 添加 `线图`，数据集选择刚才的截线。
5. 表达式填写 `spf.U`、`T` 或 `p`。
6. 可直接在 COMSOL 中出图，也可右键 `导出 > 数据` 输出 CSV 后用 Python 统一画图。

### 4.3 可由COMSOL数据整理出的曲线图

COMSOL结果不只能以云图展示。对于论文而言，曲线图和柱状图往往比云图更容易说明“变化趋势”和“指标差异”。推荐优先整理以下几类图：

| 图类型 | 数据来源 | 适合说明的问题 | 论文用途 |
| ------ | -------- | -------------- | -------- |
| 沿主流方向速度剖面 | `截线 2D/3D`，表达式 `spf.U` | 阵列前后局部加速、尾迹恢复情况 | 解释速度场云图中的高速区和低速区 |
| 沿主流方向温度剖面 | `截线 2D/3D`，表达式 `T` | 热尾迹扩散、高温区衰减 | 支撑温度场云图和平均温升结果 |
| 沿主流方向压力剖面 | `截线 2D/3D`，表达式 `p` | 压力沿程降低、局部压降集中位置 | 解释压降和摩擦因子变化 |
| 出口截面温度分布 | 出口边界截线或表面数据 | 出口温升均匀性、带热能力 | 辅助说明空气带走热量的能力 |
| 基准/优化指标柱状图 | `派生值` 或结果CSV | Nu、f、R'_th、R_th、Δp等指标差异 | 替代表格的直观展示 |
| 参数-指标响应曲线 | 多组COMSOL结果CSV | 参数变化对Nu、f、η的影响趋势 | 支撑参数敏感性分析 |

注意：曲线图必须来自COMSOL导出的同一物理量、同一截线位置和同一单位。不能把不同截线、不同色标或不同模型口径的数据放在同一张图中直接比较。

### 4.4 导出云图

1. 新建二维或三维绘图组。
2. 添加 `表面图`、`切面图` 或 `等值线图`。
3. 统一以下设置：
   - 相同视角；
   - 相同色标范围；
   - 相同坐标范围；
   - 相同分辨率；
   - 图中不放大标题，图题放正文。
4. 导出 PNG 用于论文正文。

## 6. 当前结论边界

- 云图用于说明局部流场、温度场和压力场的空间分布现象；
- 指标表用于给出最终性能判断；
- 标量统计图和剖面线图用于把云图现象与性能指标连接起来；
- 未导出的剖面线数据不能在正文中写成已完成结果，只能列为后续补充项。
