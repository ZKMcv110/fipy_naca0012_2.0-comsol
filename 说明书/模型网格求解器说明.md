# 模型、网格和求解器说明

本文档详细介绍了本项目中三个核心组件的功能和使用方法：模型生成脚本[naca0012dat.py](file:///f:/pyProject/fipy_naca0012_2.0/naca0012dat.py)、网格生成脚本[网格生成器2_三角形.py](file:///f:/pyProject/fipy_naca0012_2.0/%E7%BD%91%E6%A0%BC%E7%94%9F%E6%88%90%E5%99%A82_%E4%B8%89%E8%A7%92%E5%BD%A2.py)和求解器脚本[求解器_pvtnf.py](file:///f:/pyProject/fipy_naca0012_2.0/%E6%B1%82%E8%A7%A3%E5%99%A8_pvtnf.py)。

## 1. 模型生成脚本 (naca0012dat.py)

该脚本用于生成NACA 0012翼型扰流柱阵列的几何模型数据。

### 1.1 功能概述
- 生成NACA 0012翼型的坐标数据
- 创建3行8列的翼型阵列
- 支持多种参数调节，包括间距、弯度、厚度等
- 输出为[airfoil_array_SYMMETRIC.dat](file:///f:/pyProject/fipy_naca0012_2.0/airfoil_array_SYMMETRIC.dat)文件供后续网格生成使用

### 1.2 参数说明
脚本接受以下参数：
- `--Tt` (默认: 0.75) - 横向间距系数
- `--Ts` (默认: 1.0) - 纵向间距系数
- `--Ta` (默认: 0.0) - 弯度系数 (对于NACA 0012翼型应保持为0)
- `--Tad` (默认: 0.5) - 交错间距系数
- `--Twa` (默认: 0.5) - 宽长比
- `--Tb` (默认: 0.12) - 厚度系数 (NACA 0012的标准厚度为12%)
- `--scale` (默认: 1.0) - 整体尺寸缩放因子
- `--output` (默认: "airfoil_array_SYMMETRIC.dat") - 输出文件名

### 1.3 使用示例
```bash
python naca0012dat.py --Tt 0.8 --Ts 1.2 --Tb 0.15
```

### 1.4 输出结果
生成的[airfoil_array_SYMMETRIC.dat](file:///f:/pyProject/fipy_naca0012_2.0/airfoil_array_SYMMETRIC.dat)文件包含所有翼型的坐标数据，每个翼型由201个点定义其上下表面。

## 2. 网格生成脚本 (网格生成器2_三角形.py)

该脚本基于生成的几何数据创建用于CFD仿真的计算网格。

### 2.1 功能概述
- 使用Gmsh工具生成二维三角形网格
- 自动读取[airfoil_array_SYMMETRIC.dat](file:///f:/pyProject/fipy_naca0012_2.0/airfoil_array_SYMMETRIC.dat)文件中的几何数据
- 创建围绕翼型阵列的计算域
- 生成FiPy兼容的.msh2格式网格文件

### 2.2 网格结构
- 计算域采用矩形边界，四周留有8倍弦长的padding
- 翼型周围网格密度较高，以捕捉边界层效应
- 计算域边界网格密度相对较低，以节省计算资源
- 网格单元类型为三角形单元

### 2.3 边界条件定义
脚本自动定义以下物理边界组：
- `inlet` - 入口边界
- `outlet` - 出口边界
- `top` - 上壁面边界
- `bottom` - 下壁面边界
- `airfoils` - 所有翼型表面边界
- `fluid` - 流体区域

### 2.4 使用方法
```bash
python 网格生成器2_三角形.py
```

### 2.5 输出结果
生成[airfoil_array.msh2](file:///f:/pyProject/fipy_naca0012_2.0/airfoil_array.msh2)网格文件，供求解器使用。

## 3. 求解器脚本 (求解器_pvtnf.py)

该脚本使用FiPy库求解Navier-Stokes方程和能量方程，计算流场和温度场。

### 3.1 功能概述
- 求解二维不可压缩粘性流动
- 考虑传热过程，计算温度场分布
- 使用SIMPLE算法处理压力-速度耦合
- 计算关键性能参数：努塞尔数(Nu)和摩擦因子(f)

### 3.2 物理模型
- 流体属性：动力粘度μ=0.1，密度ρ=1.0，来流速度U=10.0
- 热物性参数：导热系数k=2.0，比热容Cp=1.0
- 边界条件：
  - 入口：速度入口，温度T=293.15K
  - 出口：压力出口，温度自由流出
  - 翼型表面：无滑移边界，恒温T=353.15K
  - 上下壁面：无滑移边界，绝热

### 3.3 数值方法
- 对流项：迎风格式
- 扩散项：中心差分格式
- 时间推进：伪时间步进法
- 压力修正：SIMPLE算法
- 线性求解器：内置线性求解器

### 3.4 收敛控制
- 最大迭代次数：300步（调试时可设为5步）
- 收敛准则：残差小于1e-4
- 松弛因子：自适应调整，根据残差大小动态变化

### 3.5 使用方法
```bash
python 求解器_pvtnf.py
```

### 3.6 输出结果
#### 3.6.1 终端输出
- 迭代过程信息
- Nu和f的计算值
- 目标参数Nu/(f^(1/3))的值

典型输出示例：
```
>>> Nu = 34.250 | f = 0.000762 <<< 
>>> 目标参数 Nu/(f^(1/3)) = 456.8 <<<
```

#### 3.6.2 文件输出
在results目录下创建时间戳命名的子目录，包含：
- 收敛历史图(convergence_history.png)
- 压力场图(pressure_field.png)
- 速度场图(velocity_x.png, velocity_y.png)
- 温度场图(temperature_field.png)
- 场数据CSV文件(field_data.csv)
- 中心线分布图(center_line_profiles.png)
- 总结报告(summary_report.txt)
- 求解器结果(solver_results/latest_solution.pkl)

## 4. 可视化结果说明

求解器会自动生成多个可视化结果，这些结果不仅用于结果分析，也是后续AI模型训练的重要数据集。

### 4.1 场变量云图
求解器会生成以下三种关键场变量的云图，这些图像构成了AI模型训练的数据集：
1. **速度场图** (velocity_field.png) - 显示整个计算域内的速度分布
2. **压力场图** (pressure_field.png) - 显示整个计算域内的压力分布
3. **温度场图** (temperature_field.png) - 显示整个计算域内的温度分布

### 4.2 图像特征描述
每张图像具有以下特征：
- **尺寸**：图像分辨率为网格节点数决定的矩形区域
- **色彩映射**：每种物理量使用不同的颜色映射方案
  - 速度场：通常使用彩虹色映射，红色代表高速区域，蓝色代表低速区域
  - 压力场：通常使用冷暖色调映射，红色代表高压区域，蓝色代表低压区域
  - 温度场：通常使用热感色彩映射，红色代表高温区域，蓝色代表低温区域
- **坐标系**：图像坐标与物理坐标相对应，保持几何形状的真实性

### 4.3 典型图像特征
根据不同物理场的特点，图像通常呈现以下特征：
- **速度场图像**：
  - 翼型前缘出现明显的驻点区域（速度为0，通常显示为深蓝色）
  - 翼型表面附近形成边界层，速度梯度较大
  - 翼型尾迹区域可能出现回流或涡旋结构
  
- **压力场图像**：
  - 翼型前缘压力最高（通常显示为红色）
  - 翼型上表面压力普遍低于下表面
  - 翼型尾缘处压力急剧下降，形成低压区
  
- **温度场图像**：
  - 入口区域温度最低（通常显示为蓝色）
  - 翼型表面温度最高（通常显示为红色），保持恒温边界条件
  - 从入口到出口，流体逐渐被加热，形成温度边界层

### 4.4 数据集准确性要求
为确保AI模型训练的质量，场变量云图必须满足以下准确性要求：
1. **充分收敛** - 求解残差应降至1e-4以下，确保物理场分布稳定可靠
2. **网格无关性** - 使用足够密的网格以捕获流场细节，特别是在边界层区域
3. **边界条件正确** - 确保所有边界条件设置符合物理实际
4. **数值稳定性** - 避免数值振荡或发散现象

### 4.5 图像规格
- 格式：PNG格式
- 分辨率：与网格分辨率相关，确保能清晰显示流场特征
- 颜色映射：每种物理量使用特定的颜色映射，便于AI模型区分不同场变量

## 5. 求解结果示例

### 5.1 性能参数范围
根据大量仿真结果统计，典型的性能参数范围如下：
- **努塞尔数 (Nu)**: 20-50（表征换热强度）
- **摩擦因子 (f)**: 0.0005-0.0015（表征流动阻力）
- **目标参数 Nu/(f^(1/3))**: 300-600（综合性能评价指标）

### 5.2 场变量分布特征
- **速度场**: 在翼型前缘出现驻点，翼型表面速度为0，尾迹区域有回流现象
- **压力场**: 翼型前缘压力最高，上表面压力低于下表面，尾缘处压力急剧下降
- **温度场**: 入口低温流体逐渐被加热，翼型表面温度最高，形成明显的温度边界层

### 5.3 收敛特征
- 残差曲线通常呈指数下降趋势
- 在50-150次迭代内达到收敛（残差<1e-4）
- 若超过200次迭代仍未收敛，可能存在问题

## 6. 工作流程

完整的仿真流程如下：
1. 使用[naca0012dat.py](file:///f:/pyProject/fipy_naca0012_2.0/naca0012dat.py)生成几何模型数据
2. 运行[网格生成器2_三角形.py](file:///f:/pyProject/fipy_naca0012_2.0/%E7%BD%91%E6%A0%BC%E7%94%9F%E6%88%90%E5%99%A82_%E4%B8%89%E8%A7%92%E5%BD%A2.py)生成网格文件

4. 查看results目录中的结果文件

注意：每个步骤都需要前一步骤的输出作为输入，因此必须按顺序执行。
