# Small Paper Figures and Tables Checklist

This checklist is based on the corrected label pipeline:

`result.json -> data_processing/rebuild_labels_from_results.py -> consol_cfddata/labels.csv -> cnnstep2.py`

## Figures

| Paper item | Use this file or source | Notes |
|---|---|---|
| Fig. 1 geometry and parameters | `Fig1_Geometry_Schematic.png` | Must show `Ta`, `Twa`, `Tb`, `Ts`, `Tt`, `Tad`. |
| Fig. 2 workflow | New schematic recommended | Show LHS sampling, COMSOL, `result.json`, field images, rebuilt labels, CNN, DE screening, CFD verification. |
| Fig. 3 representative CFD fields | `consol_cfddata/case_*_cfd_solution/*.png` | Use true COMSOL velocity, pressure, and temperature fields. Prefer baseline vs optimized cases. |
| Fig. 4 CNN architecture | `Fig2_CNN_Architecture.png` or regenerated architecture figure | Must match the 3 image inputs plus 6 scalar inputs. |
| Fig. 5 training loss | `ai_cnn_model_results/loss_curve.png` | Generated by `cnnstep2.py`. |
| Fig. 6 test prediction scatter | `ai_cnn_model_results/final_prediction.png` | Regenerated without artificial jitter. |
| Fig. 7 baseline vs optimal CFD comparison | Need independent COMSOL verification | Do not use CNN prediction alone as final evidence. |

## Commands

Regenerate labels:

```powershell
.\myenvs_fipynaca2.0\Scripts\python.exe .\data_processing\rebuild_labels_from_results.py
```

Train with all valid data:

```powershell
.\myenvs_fipynaca2.0\Scripts\python.exe cnnstep2.py
```

Train with a selected number of cases:

```powershell
.\myenvs_fipynaca2.0\Scripts\python.exe cnnstep2.py --num-samples 300 --sample-mode random --seed 42
```

Recalculate paper metrics from the existing trained model:

```powershell
.\myenvs_fipynaca2.0\Scripts\python.exe cnnstep2.py --eval-only
```

Train the scalar-only MLP baseline and regenerate Table 8:

```powershell
.\myenvs_fipynaca2.0\Scripts\python.exe train_mlp_baseline.py
```

Train the multimodal feature-fusion model and regenerate Table 8:

```powershell
.\myenvs_fipynaca2.0\Scripts\python.exe train_multimodal_feature_model.py
```

Regenerate SVG figures:

```powershell
.\myenvs_fipynaca2.0\Scripts\python.exe .\comsol论文图脚本\generate_paper_svgs.py
```

Regenerate all COMSOL/CNN paper SVG figures from one entry point:

```powershell
.\myenvs_fipynaca2.0\Scripts\python.exe .\comsol论文图脚本\generate_comsol_svgs.py
```

Regenerate heat-dissipation evidence figures:

```powershell
.\myenvs_fipynaca2.0\Scripts\python.exe .\comsol论文图脚本\make_heat_dissipation_evidence.py
```

Note: `cnnstep2.py` now saves `ai_cnn_model_results/cnn_training_history.csv`. If this CSV exists, `generate_paper_svgs.py` redraws the CBAM attention CNN loss curve as a true vector SVG. For older runs that only have `loss_curve.png`, the script digitizes the existing curve into `cnn_training_history_digitized.csv` and redraws a clean no-grid SVG.
