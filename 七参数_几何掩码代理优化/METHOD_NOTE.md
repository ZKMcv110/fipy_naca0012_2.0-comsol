# 方法说明

## 1. 代理模型的作用

代理模型用于替代高成本 CFD 计算，快速估计某一组几何参数对应的 `Nu` 和 `f`。它不是替代 COMSOL 的最终物理验证，而是在参数搜索阶段提供快速评价。

## 2. 为什么标签是 Nu 和 f

`Nu` 表征气侧对流换热能力，`f` 表征流动阻力或压降代价。优化目标通常不是单纯提高换热，而是在换热增强和阻力增加之间取得折中，因此用 `Nu` 和 `f` 作为代理模型输出，再构造综合评价因子：

```text
eta = (Nu/Nu0) / (f/f0)^(1/3)
```

## 3. 几何掩码与 CFD 云图的区别

几何掩码图由参数直接生成，只包含翼型阵列的空间形状和排布信息。它不包含速度、温度、压力等 CFD 结果。

CFD 云图是 COMSOL 求解后的结果，包含流动和传热响应。若优化阶段把 CFD 云图作为输入，就意味着每个候选结构已经完成仿真，代理模型失去加速优化的意义。

因此新流程使用：

```text
参数 + 几何掩码图 -> 代理模型 -> Nu, f
```

而不是：

```text
参数 + CFD云图 -> 代理模型 -> Nu, f
```

## 4. 差分进化的作用

差分进化是参数搜索算法。它只负责在七参数范围内产生候选结构，并根据代理模型预测结果计算 `eta`。差分进化本身不是 CFD，也不是神经网络。

完整关系是：

```text
差分进化生成参数
参数生成几何掩码
CNN/MLP代理模型预测 Nu 和 f
根据 eta 评价候选结构
输出最优七参数
COMSOL 对最优结构复核
```

## 5. COMSOL 的作用

COMSOL 只用于两个阶段：

1. 生成训练、验证、测试样本标签。
2. 对差分进化得到的最优结构进行最终复核。

差分进化迭代过程中不调用 COMSOL。

## 6. theta 参数的物理意义

`theta` 表示翼型整体相对来流方向的倾斜角，单位为 degree。脚本中先按 `Ta, Twa, Tb` 生成翼型截面，再绕翼型自身弦长中点旋转 `theta`，最后按 `Ts, Tt, Tad` 放置到 3×8 阵列中。

## 7. 与旧六参数流程的关系

旧六参数流程保留，适合作为历史结果和对照结果。新七参数流程是独立新增流程，解决“优化阶段不能依赖 CFD 云图输入”的问题。

如果使用旧 `labels.csv` 扩展出 `theta=0` 标签，只能用于程序链路调试；要研究 theta 的真实影响，必须用七参数 COMSOL 脚本重新生成包含不同 theta 的样本。
